# 和音 · 桌面版 0.5.1

一个简洁、无广告的 Windows 音乐应用，包含账号后端、QQ 音乐与网易云音乐扫码登录、平台歌单同步和本地音乐播放。

0.4.0 将播放模式合并为一个按钮：列表循环 → 随机播放 → 单曲循环，悬浮可查看当前模式与下一模式。歌单卡片与详情页默认显示第一首歌的封面，未打开的平台歌单也会懒加载首曲封面，失败回退默认封面。全部歌单页增加和音歌单 / QQ 音乐 / 网易云音乐页签。欢迎页支持「不登录，先在本地使用」，无需注册即可绑定音乐平台，平台凭据、歌单和收藏保存在本地，重启恢复，可从设置切换回和音账号，两种模式的数据相互独立。

0.3.3 支持左侧歌单分组单独展开 / 收起，点击「我的歌单」可全部展开 / 收起，状态按账号保存在后端。新增独立歌单名称搜索，搜索时自动展开匹配结果，清空或按 Esc 恢复原折叠状态。

0.3.2 将平台歌单区改为可点击切换的 QQ 音乐 / 网易云音乐页签，显示各平台歌单数量；一次只显示选中平台，支持键盘方向键切换。

0.3.1 将音乐平台页的「平台歌单」卡片区按 QQ 音乐、网易云音乐分区，沿用账号在后端保存的分组及组内排序，各平台分别显示歌单数量与空状态。

0.3.0 完成本轮交互优化：自建 / QQ / 网易云歌单分组、分组及组内拖动排序（按账号保存在后端，支持版本冲突检测）；歌曲整行播放与真实平台封面；更明显的悬浮反馈、输入法友好的即时搜索；普通歌曲列表移除大小列，下载管理显示实际大小；音乐平台入口移到账号下方；播放页与首页同步歌词、翻译和点击跳转；支持可拖动置顶的桌面歌词、字号调整与锁定穿透。客户端服务器配置入口和原生菜单栏已移除。

## 直接使用

### 网页预览与交付流程

运行 `npm run preview` 后打开 `http://127.0.0.1:47831`。预览与 Windows 客户端直接共用 `web/` 源码，修改界面后刷新即可查看；后端修改会自动重启预览服务。预览首次建立独立的示例资料库 `.preview-data/`，包含明确标注的示例歌单、封面与合成音轨；不会访问或修改正式客户端的数据。示例资料可自由调整，后续启动保留修改。

预览默认免登录进入。账号设置中可以切换到登录页面；音乐平台页也可扫码绑定真实账号，但这些绑定只保存在预览资料库。浏览器不提供原生桌面歌词窗口。

**后续先更新网页让用户查看；只有用户明确发出打包指令，才更新版本、构建 Windows EXE。**

“我的歌单”中，新建歌单右侧可导出或导入歌单 JSON 文件。导出包含喜欢列表和全部自建歌单；导入会新建缺少的歌单、合并同名自建歌单并按平台歌曲标识去重，重复导入不重复添加。文件不包含音频或平台凭据，播放使用当前连接的平台账号，无需与导出时相同；未绑定对应平台时会显示提示和连接入口。

运行 `npm run test:playlists:ui` 可验证真实文件下载和导入、同名合并、重复导入、未绑定提示及不同平台账号下的播放链路。该自动化测试使用受控平台适配器与音频响应，浏览器实际解码播放；不代表真实平台的版权或会员权限测试。

Windows 下运行 `npm run dist` 可构建 x64 便携版，产物位于 `release/`。便携版运行时内置后端。首次解包启动可能需要稍等。更新前先关闭旧版软件，现有账号与歌单会保留。

首次使用也可直接点击「不登录，先在本地使用」，进入音乐平台扫码绑定 QQ / 网易云账号。本地模式不会向配置的远程账号服务写入资料，平台凭据仍加密保存在本地；退出软件不会删除本地资料。需要账号模式时点击左下角「本地模式」中的「登录和音账号」。本地资料不会自动合并进账号。

1. 选择「注册账号」，自行设置用户名和密码。不需要邮箱或验证码。
2. 新用户名为 3–32 位，只允许小写字母 `a–z` 和数字 `0–9`；密码为 8–128 位。旧版已注册账号仍可登录。
3. 进入「音乐平台」，点击「扫码登录」：QQ 音乐使用**手机 QQ 的扫一扫**；网易云音乐使用**网易云音乐 App 扫一扫**。在手机上确认后，软件验证平台账号并同步歌单。
4. 平台歌单只读，可打开读取歌曲、搜索及播放有权限的曲目，也可以加入自己的歌单。本地音乐通过「打开本地音乐」直接播放，不上传；文件仅在当前会话可用，刷新或重启后需重新打开。旧版存储的音频仍可播放和下载。
5. 退出账号，再登录同一账号，歌单和音乐仍然保留。

软件默认启动**这台电脑上的内置后端**。歌单等业务数据保存在后端 SQLite 数据库，不在浏览器 localStorage 中。不同账号相互隔离，但这不等于已经部署了公网云服务。

注册时勾选「保持登录 30 天」会保存登录会话。取消勾选则使用最长 24 小时的会话 Cookie，关闭客户端后需重新登录。可在设置中修改密码，修改后其他设备的登录会话失效。当前没有邮件服务或忘记密码找回，请妥善保管密码。

## 当前已实现

- Windows 桌面应用：原生窗口、独立运行、内置本地后端，也可连接远程 HTTPS 后端。
- 用户名和密码注册、登录、保持登录、退出、修改密码。
- 密码使用带随机盐的 scrypt 派生值保存；会话凭据仅以哈希存入数据库，浏览器使用 HttpOnly Cookie。
- 歌单新建、改名、介绍、封面颜色、删除；歌曲添加、移除、顺序调整；同一首歌不能重复加入同一歌单。
- 收藏、最近播放和所有歌单内容按账号持久化；修改成功后才显示已保存。
- 多窗口修改使用歌单版本号检查，遇到冲突会刷新并提示重试，防止静默覆盖。
- 本地文件直接播放、已有音频兼容、真实播放、暂停、上一首/下一首、进度、音量、队列、随机、循环和下载原文件。
- 全部音乐搜索、平台来源筛选、浅色/深色外观、键盘快捷键。
- 两平台真实二维码与状态轮询、超时刷新、取消、解除连接；成功授权才保存登录状态。
- 平台账号凭据在后端用 AES-256-GCM 加密保存，按和音账号隔离，不返回前端。
- 平台歌单列表同步，打开时读取歌曲；平台搜索结果可加入自建混合歌单。

## 当前边界

两平台适配器直接访问平台域名，通过其现有客户端协议完成登录、搜索、歌单读取和音频地址请求，不使用第三方凭据代理。此接入不是平台提供的稳定开放 API，接口变化、网络或账号限制可能造成失败；软件会显示错误并允许重试。两平台均已由用户扫码确认并完成真实账号连接。QQ 已实测读取昵称、40 张自建与收藏歌单，以及“我喜欢”的全部 365 首歌曲；网易云账号已同步 47 张歌单。会员曲目完整播放尚未实测，歌单读取成功不代表全部曲目都可播放。

下载保留「可下载 / 不可下载」两种状态。当前账号自己导入的文件可以下载；平台曲目没有独立下载授权，下载按钮置灰。播放也受平台返回的权限限制，不提供会员、付费或地区限制绕过。平台歌单只保存只读快照，不回写平台。

本版本为未签名开发构建，尚未配置 Windows 代码签名或自动更新。已验证 Windows 11 x64；其他 Windows 版本未实测。本地文件暂不读取 ID3 内嵌封面或本地歌词；歌曲封面随歌单刷新或搜索读取；未加载的平台歌单卡片会单独请求首曲封面，不需要先打开整张歌单。平台未返回歌词时显示明确的空状态，接口失败可刷新重试。下载记录保留在当前会话，实际保存由系统下载窗口完成。

## 数据位置与备份

默认数据目录如下（也可由管理员通过 HARMONY_USER_DATA 指定）：

```text
用户数据目录/
  connection.json          # 后端连接设置
  backend/
    harmony.sqlite         # 账号、会话、歌单、音乐索引、收藏、最近播放
    harmony.sqlite-wal     # 运行中可能存在
    harmony.sqlite-shm     # 运行中可能存在
    platform.key           # 平台凭据加密密钥，必须与数据库一起备份
    media/                 # 账号导入的原始音频文件
```

退出软件后备份整个 `backend` 目录。数据库、`platform.key` 和 `media` 必须一起备份；密钥丢失将无法解密平台凭据。数据库版本 2 自动迁移旧数据，升级后不要用旧版程序打开。删除程序文件不会主动删除账号数据；删除用户数据目录会丢失本地后端资料。

客户端已移除音乐存储与导入入口。支持打开 MP3、WAV、FLAC、OGG、M4A、AAC 本地文件直接播放；具体编码是否可播放取决于 Chromium 解码支持。后端旧导入接口和存量数据保留兼容。

## 独立后端工程

后端已拆至相邻目录 [harmony-backend](../harmony-backend/README.md)，独立管理 `package.json`、锁文件、环境配置、Dockerfile、业务源码及 API 测试。默认提供 `http://127.0.0.1:47832/api`，不依赖或自动寻找前端目录。

```powershell
cd ../harmony-backend
npm ci
npm start
npm test
```

后端部署配置见后端 README 和 `.env.example`。客户端只通过本地包 `harmony-backend` 引用业务实现；桌面本地模式和网页预览由客户端显式传入前端资源目录与原数据目录。客户端安装前先安装后端依赖。

需要切换正式账号服务时，仍由管理员维护 `HARMONY_SERVER_URL` 或客户端数据目录下的 `connection.json`，不向用户开放服务器设置入口。

## 歌词与排序

点击底部正在播放的歌曲或「词」打开播放页。歌词自动跟随进度，可点击任意句跳转；首页也显示当前句。底部「桌」切换桌面歌词窗口，窗口置顶，可拖动、调整大小和字号；锁定后鼠标穿透，按 Ctrl Shift L 解锁。若快捷键被占用或不可用，会提示回到和音点击「桌」关闭并解锁。关闭主窗口或退出账号会关闭桌面歌词。

左侧组标题拖动调整三个分组的顺序，歌单可在所属分组内拖动。排序通过 /api/playlist-layout 写入账号的 SQLite 数据，不使用本地 localStorage；其他设备重新读取资料库后恢复排序。同步新增的歌单追加到对应分组，删除的歌单自动忽略。多端同时修改发生版本冲突时会刷新并提示重新拖动。

## 按需求修改

界面布局、样式、搜索和播放交互修改 `web/`；窗口、桌面歌词和本地模式桥接修改 `desktop/`；账号、平台适配、接口、数据与权限修改 `../harmony-backend/`。只有接口契约确实变化时才联动修改两端。保持先网页预览、用户查看、收到打包指令再生成 EXE 的流程。


1108 网页预览：平台页和歌曲来源列使用需求中指定的 QQ / 网易云 SVG；首页我的歌单提供和音 / QQ / 网易云分组。喜欢状态在列表与歌词页同步显示红色实心爱心，更多菜单的删除仅作用于当前和音歌单或喜欢列表。底栏显示当前歌词，播放页封面随窗口调整。

本地模式的「登录和音账号」通过弹窗完成，保持当前音源和播放进度；本地数据不会自动合并进账号。Windows 配置远程账号服务时，由原生外壳在本地同源入口转接远程 API，账号会话保存在独立 Electron 持久化分区，当前本地音频继续读取本地服务。登录成功后重启恢复账号模式。未生成新的 EXE。

## 0.5.0 交付与 Mac 构建

Windows 支持单文件便携 EXE（`npm run dist`）和文件夹版（`npm run dist:dir`）。0.5.0 曾验证打包程序的启动、本地路径引用播放、HY 导入导出、重启恢复及桌面歌词。

在 Mac 上安装 Node.js 22.14+ 后，从客户端目录运行 `npm run dist:mac`。脚本生成 Apple 芯片版和 Intel 版 DMG，位于 `release/0.5.0/`。安装包使用本机临时签名，未进行 Apple 公证。Mac 版启动后直接打开本地首页，保留置灰的和音账号入口。内置服务仅提供本机音乐所需接口。
