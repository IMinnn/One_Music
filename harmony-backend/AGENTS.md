# 后端工程约定

- 本工程负责账号、平台登录与适配、歌单、歌词接口、音频传输、数据持久化与权限校验。
- 保持独立可运行：不要导入 `../harmony/web`、Electron、Playwright 或客户端业务代码。
- 默认只提供业务 API。需要承载前端资源时，由客户端组合入口显式传入 `webDir`；不硬编码客户端路径。
- 后台服务配置放在本工程的环境变量和部署文件，不向产品界面增加服务器配置入口。
- 修改数据库时保留现有账号与数据，调整接口时同步更新接口文档。只有客户端使用方式确实改变才联动修改客户端。
- 本工程的检查命令是 `npm test`。打包 Windows 的规则以工作区根目录 `AGENTS.md` 为准。
