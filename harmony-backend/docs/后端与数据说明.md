# 后端与数据说明

本工程已独立为 `harmony-backend`。默认启动端口 47832，仅提供 API；前端资源由客户端组合入口显式通过 `webDir` 提供。

## 本次范围变更

2026-11-06：目标从 macOS 改为 Windows。用户进一步明确暂不做邮箱注册和验证码，改为自定义用户名、密码自由注册。自建歌单从旧原型的 localStorage 改为后端按账号存储；不回写 QQ 音乐或网易云的规则保留。

2026-11-09：Mac 安装包使用本机入口 `harmony-backend/local`。该入口通过设备内会话提供歌单、收藏、音频与音乐平台接口。下方列出的和音账号注册、登录、退出和改密接口由独立服务提供。

## API

全部 JSON 接口使用 `/api` 前缀。写入 JSON 需 `Content-Type: application/json`。所有写请求必须携带与服务器 `PUBLIC_ORIGIN` 相同的 Origin。除注册、登录、退出及健康检查外，接口需要会话 Cookie。

| 方法 | 路径 | 功能 |
|---|---|---|
| GET | `/health` | 服务健康与版本 |
| POST | `/auth/register` | `{username,password,remember}`，注册并建立会话 |
| POST | `/auth/login` | 用户名密码登录 |
| POST | `/auth/guest` | 仅内置服务接受桌面进程私钥建立本机身份；普通与生产服务禁用 |
| POST | `/auth/logout` | 撤销当前会话并清除 Cookie |
| POST | `/auth/password` | `{currentPassword,newPassword}`，改密并撤销旧会话 |
| GET | `/me` | 当前账号 |
| GET | `/library` | 当前账号的音乐、歌单、收藏、最近播放、平台状态与存储配额 |
| POST | `/library/aggregate` | `{}`，补齐已连接平台尚未加载的歌单歌曲；返回 `{loaded,errors:[{playlistId,provider,message}]}`，失败歌单可重试，同账号并发请求合并 |
| PUT | `/playlist-layout` | `{version,groups,lists}`，保存本人分组顺序和各组歌单顺序；版本冲突返回 409 |
| GET | `/tracks/:id/lyrics` | 本人歌曲的平台 LRC 与翻译；本地歌曲返回空歌词 |
| GET | `/providers` | 当前账号的平台连接状态，不含凭据 |

| DELETE | `/providers/:provider/qr/:id` | 取消本人二维码 |

| DELETE | `/providers/:provider` | 删除凭据与平台歌单快照；保留自建歌单曲目 |
| POST | `/providers/search` | `{query,provider,pages?}`，provider 可为 all / qq / netease；无需绑定音乐平台，已有可用授权时使用授权搜索；pages 如 `{qq:2,netease:3}`，仅请求指定平台对应页，省略时请求第一页。每页 30 条；响应保留 trackIds/errors，新增 pagination：`[{provider,ids,page,hasMore}]`。失败平台不推进页码，可重试；无更多结果时 hasMore 为 false |
| POST | `/platform-playlists/:id/refresh` | 读取本人平台歌单歌曲 |
| GET | `/platform-playlists/:id/cover` | 仅获取首曲封面，缓存后重定向到允许的平台图片域名 |
| POST | `/playlists` | `{name,description,color}`，创建歌单 |
| GET | `/playlists/:id` | 读取本人歌单 |

| DELETE | `/playlists/:id` | `{version}`，删除本人歌单 |
| PUT | `/playlists/:id/tracks` | `{version,trackIds}`，替换歌曲集合与顺序 |

| GET | `/tracks/:id/audio?download=1` | 原文件附件下载 |
| PUT | `/tracks/:id/favorite` | `{favorite:boolean}`，设置收藏 |

## 存储与一致性

SQLite 开启外键、WAL 与 busy timeout。`users`、`sessions`、`rate_limits`、`tracks`、`playlists`、`playlist_tracks`、`favorites`、`recent_tracks` 是当前表。

所有资源由服务端根据会话取得 user_id；客户端无法指定归属账号。曲目加入歌单前逐项检查账号归属。音乐文件采用服务端生成 UUID 命名，不采用用户传入路径。上传完成且格式头校验通过后才写入索引，失败时清理临时文件；用户配额和同账号同时上传数量受限。

歌单 `version` 每次修改递增。写入要求客户端提交读取到的版本，后端返回 409 代表发生冲突。曲目列表替换在同一数据库事务中完成。删除整首音乐会更新所有受影响歌单版本，再通过外键清理关联。

SQLite 适合当前单服务进程部署。多实例、大规模并发、数据库迁移管理、对象存储、跨后端迁移与自动备份尚未实现；不能简单让多个独立数据库实例自动共享账号。

## 身份验证

新注册用户名严格匹配 `^[a-z0-9]{3,32}$`。旧账号登录保留 NFC 归一及原字符兼容，不将大写的新用户名静默转为小写。密码 scrypt 参数 N=16384、r=8、p=1，随机 16 字节盐、64 字节派生值；验证使用恒定时间比较。未知账号同样执行派生，登录错误不区分账号或密码。

会话使用 32 字节随机令牌；数据库存 SHA-256 哈希，Cookie 设置 HttpOnly / SameSite=Strict，生产 HTTPS 模式强制 Secure。密码变更会撤销全部旧会话并重新签发当前会话。注册、登录、修改密码具有限流，账号与会话不会输出到日志。

前端无 Node 权限；Electron 开启 contextIsolation、sandbox 与 webSecurity，限制导航、弹窗和权限请求。客户端预加载仅暴露本地模式切换和歌词相关桥接，校验调用窗口与来源；服务器配置由管理员维护，不开放给用户。

## 平台接入与迁移

数据库 user_version 从 1 迁移到 2，新增 provider_connections 与歌单 remote_id / track_count / loaded_at。`tracks.provider` 支持 local / qq / netease，provider_id 为平台曲目 ID；连接、歌单、曲目均按 user_id 隔离。平台凭据用数据目录 platform.key 加密，AES-256-GCM 的附加认证数据含 user_id 和 provider。

二维码只在内存保存，三分钟失效，关闭或退出时取消。取消后的迟到成功结果不写入。平台授权失效返回 PROVIDER_AUTH_EXPIRED，不会登出和音账号。网络错误不覆盖已保存的歌单；平台切换账号时清除旧平台歌单快照。

NetEase 使用现有 web weapi 协议；QQ 使用 ptqrshow / ptqrlogin / check_sig / OAuth code / QQLogin 交换，再验证平台账号。这些是第三方平台客户端协议适配，不是官方开放平台合作集成。参考与许可证见 src/providers/THIRD_PARTY_NOTICES.txt。

音频由后端从允许的平台 CDN 域名代理，逐次校验重定向，支持 Range，不向 CDN 转发登录凭据。仅返回平台本身许可的地址，不加入解锁或替代音源。平台曲目没有独立下载授权，下载入口返回 403。账号导入的本地文件保留原有下载行为。


### 1108 预览交互调整

- 客户端新打开的本地音频使用浏览器 File/Blob 直接播放，不上传、不占用服务端存储；刷新后需重新打开。旧版导入接口及已有音频数据保留兼容，客户端不再提供上传入口。
- `POST /api/auth/login` 可选 `continueTrackId`：仅当登录请求携带有效的本地模式会话、且歌曲属于该本地身份时，为新会话保留这一首歌最多两小时的音频/歌词读取权限。下载、收藏、歌单及其他歌曲不开放；退出后撤销。这支持登录弹窗成功后原音频及 Range 请求继续播放，不迁移本地资料库。
- QQ 搜索依次尝试默认桌面参数、另一桌面参数和网页搜索接口；有效空结果不回退，登录过期直接返回，备用接口均失败仍报告真实错误。

### 全部音乐与搜索缓存

`GET /library` 的 `tracks` 包含播放、搜索所需的歌曲缓存；`collectionTrackIds` 是“全部音乐”的去重汇总成员（平台/自建歌单、收藏、本地音乐），不含仅搜索过的歌曲。旧缓存无需删除或迁移。客户端进入“全部音乐”时调用 `/library/aggregate` 补齐尚未加载的平台歌单，再刷新资料库。

## 歌单文件导入与导出

- `GET /api/playlists/export`：需要登录，返回 JSON 附件。包含当前身份的喜欢列表和全部 `source=own` 歌单，不包含平台歌单、凭据、文件路径或音频。
- `POST /api/playlists/import`：需要登录和同源请求，接收上述文件（最大 20 MB）。格式为 `{format:"harmony-playlists",version:1,exportedAt,favorites:[Track],playlists:[{name,description,color,tracks:[Track]}]}`，Track 为 `{provider,providerId,title,artist,album,duration}`。
- 按当前身份的歌曲来源和歌曲标识复用记录。每张歌单和喜欢列表分别去重；保留不同平台及版本的歌曲。无同名自建歌单时新建，有同名时按创建顺序合并到第一张，保留原介绍、颜色和歌曲顺序，追加新歌。文件中的同名条目同样合并；不会改写平台歌单。
- 原子导入：格式错误或合并超过每张 5000 首、总共 500 张自建歌单时整批回滚。单次最多 100000 条歌曲记录。返回 `{created,merged,added,skipped}`，added/skipped 为喜欢列表与各歌单中的收藏条目数。同一首歌出现在不同歌单属于不同收藏条目。
- 本地歌曲仅恢复记录；若目标身份没有对应音频，记录不可播放。平台歌曲在连接对应平台后按现有播放规则使用。已有歌曲文件与元数据不受导入影响。
- 导入不校验或携带导出时的平台账号。播放使用目标身份当前绑定的平台凭据，支持不同 QQ / 网易云账号；未绑定时音频接口返回 `409 PROVIDER_NOT_CONNECTED`，错误中包含所需平台名称，客户端提供连接入口。版权、会员权限与授权有效性由平台判定。


### 歌曲展示字段

`GET /api/library` 的歌曲新增 `releaseDate`（平台提供的发表日期，`YYYY-MM-DD`，未知为空字符串）和 `playCount`（平台明确提供的歌曲播放次数，未知为 `null`，真实的 0 保留）。`album` 继续表示专辑名。不会使用入库时间、热度、评论数或专辑/歌单播放量替代歌曲发表时间与播放量。平台同步或搜索时更新这些字段；旧记录保留，缺失信息显示未知。

歌曲额外返回 `favoriteCount`，表示平台明确提供的单曲收藏总量，缺失为 `null`，真实的 0 保留。只映射歌曲的 favoriteCount / collectCount / collect_count；不使用本账号的喜欢状态、歌单收藏数、评论数或热度替代。
